# مسلك GPS — MaslakGPS

تطبيق Android لتغيير الموقع (Fake GPS) بواجهة عربية داكنة، مكتوب بـ Kotlin و Jetpack Compose.

## المميزات
- **بحث ذكي**: اسم مكان، إحداثيات (`24.7136, 46.6753` — يدعم الأرقام العربية)، أو رابط Google Maps بكل أشكاله بما فيها الروابط المختصرة `maps.app.goo.gl`.
- **دقة عالية**: يحقن الموقع في جميع المصادر: GPS + Network + Fused (النظام) + Fused (خدمات Google Play) مع `accuracy` و `altitude` و `speed` و `bearing` و `elapsedRealtimeNanos` وتحديث كل 500ms (قابل للتعديل حتى 100ms).
- **خريطة** OpenStreetMap داكنة + قمر صناعي، مع تكبير لملء الشاشة (بدون مفتاح API).
- **حفظ / المحفوظات / استعادة** الموقع السابق.
- **مسار**: ارسم نقاطاً على الخريطة ويتحرك الموقع عليها بالسرعة المحددة (مع تكرار).
- **عشوائي**: حركة طبيعية داخل نطاق حول الدبوس.
- **الجدولة**: بدء متأخر وإيقاف تلقائي.
- **تخصيص**: الدقة، سرعة التحديث، السرعة، الارتفاع، نطاق العشوائي، الاهتزاز الطبيعي.
- استقبال روابط Google Maps عبر زر "مشاركة" من أي تطبيق.
- يعمل في الخلفية عبر Foreground Service مع زر إيقاف في الإشعار.

## التثبيت
1. حمّل ملف APK من تبويب **Actions** في GitHub ← آخر تشغيل ناجح ← **Artifacts** ← `MaslakGPS-debug-apk`.
2. ثبّته على الهاتف (اسمح بالتثبيت من مصادر غير معروفة).

## التفعيل
1. الإعدادات ← حول الهاتف ← اضغط "رقم الإصدار" 7 مرات.
2. خيارات المطور ← **اختيار تطبيق الموقع الوهمي** ← MaslakGPS.
3. افتح التطبيق، حدد الموقع، وفعّل "تفعيل تغيير الموقع".

## البناء محلياً
يتطلب Android Studio أو Android SDK (API 35) و JDK 17:
```bash
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## ملاحظات
- يدعم Android 7.0 (API 24) فما فوق.
- بعض التطبيقات تكشف المواقع الوهمية أو تمنعها في شروط استخدامها؛ استخدم التطبيق بمسؤولية.
